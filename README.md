# Student Grade Tracker

A simple Java console application to manage and analyze student grades.

## Features
- Takes marks input from the user
- Calculates the average score
- Finds the highest and lowest marks
- Shows total number of students
- Displays all entered marks

## How to Run
1. Open StudentGradeTracker.java in any Java IDE or VS Code
2. Run the program
3. Enter marks between 0 and 100
4. Enter -1 to stop entering marks
5. The program will show Average, Highest, Lowest and Total Students

## Technologies Used
- Java
- Scanner Class
- ArrayList
